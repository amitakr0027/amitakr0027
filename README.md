## Featured Project

### [FoodSnap](https://foodsnap-plum.vercel.app) - AI-Powered Food Analysis Platform

An intelligent food scanning application that provides instant nutritional analysis, allergen detection, and health insights using AI.

**Tech Stack:** Next.js 14 • TypeScript • Google Gemini AI • Firebase • Tailwind CSS

**Key Features:**
- Real-time barcode scanning with camera integration
- AI-powered nutritional analysis and health scoring
- Personalized allergen warnings based on user profiles
- Scan history tracking and favorites management
- Server-side API security with no exposed credentials

**Architecture Highlights:**
- Clean separation of concerns with modular design
- Server-only AI inference for security
- Optimized rendering with virtual lists and debouncing
- TypeScript strict mode for type safety
- Production deployment on Vercel with 95+ Lighthouse score
